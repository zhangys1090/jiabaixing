# jiabaixing智能助手性能测试报告

## 1. 测试概述

### 1.1 测试目标
验证jiabaixing在单用户本地部署场景下的核心交互体验是否达到"真人级"流畅度，并评估在多任务并发、大量记忆检索场景下的资源瓶颈，确保在推荐配置（8核16G）下长期稳定运行。

### 1.2 测试环境
- **操作系统**: Ubuntu 22.04 / Windows 11 / macOS 14
- **CPU**: Intel i7-10700K (8核16线程) 或 Apple M1 Pro
- **内存**: 16GB DDR4 / 16GB Unified Memory
- **存储**: NVMe SSD (读取速度≥2000MB/s)
- **软件版本**:
  - Node.js 20 LTS
  - Ollama 0.3.6 (加载 gemma2:9b 或 qwen2.5:7b)
  - ChromaDB 0.5.x (Docker运行或本地二进制)

## 2. 测试方法

### 2.1 测试工具
- **应用层埋点**: PerformanceMonitor类，在关键路径打点并输出JSON日志
- **系统资源**: node-os-utils 输出到控制台
- **LLM推理监控**: Ollama自带/api/ps接口
- **内存分析**: Node.js --inspect + Chrome DevTools

### 2.2 测试场景
1. **单会话长上下文压力测试**
   - 预先注入1000条用户历史记忆
   - 模拟用户连续发送50轮对话
   - 测量第1轮和第50轮的性能变化

2. **混合负载测试**
   - 1个长对话流（用户正常闲聊）
   - 2个后台任务：git log分析 + 代码文件语法检查
   - 记忆系统异步写入

3. **本地模型推理极限测试**
   - 持续向Ollama发送请求，逐步增加请求频率
   - 测量最大Token生成速度和并发请求数
