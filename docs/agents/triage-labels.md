# Triage Labels

| Label             | Meaning                                      |
| ----------------- | -------------------------------------------- |
| `needs-triage`    | New issue, not yet classified                |
| `needs-info`      | Waiting on reporter for more detail          |
| `ready-for-agent` | Scoped and ready for an AI agent to pick up  |
| `ready-for-human` | Requires human judgement or action           |
| `wontfix`         | Accepted but will not be fixed               |
