### **阶段3：实现最小可用工具集**

**目标**：让核心引擎能真正调用工具完成文件读写和命令执行，为 P0 闭环测试铺路。

#### **子任务 3.1：创建工具执行器骨架**

在 `src/tools/ToolExecutor.ts` 中创建：

```typescript
import { exec } from 'child_process';
import fs from 'fs/promises';
import { promisify } from 'util';

const execAsync = promisify(exec);

export class ToolExecutor {
  async execute(toolName: string, params: any): Promise<any> {
    switch (toolName) {
      case 'read_file':
        return await fs.readFile(params.path, 'utf-8');
      case 'write_file':
        return await fs.writeFile(params.path, params.content, 'utf-8');
      case 'run_command':
        const { stdout, stderr } = await execAsync(params.command, { cwd: params.cwd || process.cwd() });
        return { stdout, stderr };
      default:
        throw new Error(`未知工具: ${toolName}`);
    }
  }
}
```

**目标**：确保所有输出符合御姐人设，高危操作触发二次确认。

#### **子任务 4.1：创建人设守卫模块**

在 `src/interaction/PersonaGuard.ts` 中创建：

```typescript
export class PersonaGuard {
  private forbiddenPatterns = [
    /指责|辱骂|贬低|pua|抬杠/i,
    /生硬|机械|列表式/i,
    /错误指导|虚假/i,
  ];

  filterOutput(raw: string): string {
    // 检测是否包含禁止内容
    for (const pattern of this.forbiddenPatterns) {
      if (pattern.test(raw)) {
        console.warn('⚠️ 输出违规，触发替换');
        return '亲爱的主人，刚刚的回复好像有点不对劲，我重新整理了一下语言～';
      }
    }
    // 确保以温柔语气开头
    if (!raw.startsWith('亲爱的主人') && !raw.startsWith('主人')) {
      raw = `亲爱的主人，${raw}`;
    }
    return raw;
  }

  checkHighRiskAction(toolName: string, params: any): boolean {
    const highRiskCommands = ['rm -rf', 'format', ':(){', 'sudo', 'chmod 777'];
    if (toolName === 'run_command') {
      return highRiskCommands.some(cmd => params.command.includes(cmd));
    }
    return false;
  }
}
```
