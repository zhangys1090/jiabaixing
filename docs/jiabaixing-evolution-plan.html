2. 关键差距分析

对照 Open Interpreter（桌面操控）和 Manus（多Agent协作），以下为完全缺失的维度。

缺失：桌面级屏幕像素识别

Playwright 只在浏览器沙箱内截图。看不到浏览器之外的桌面区域（文件管理器、Office、微信等任意应用）。

目标：screenshot-desktop + OCR + UI元素检测，覆盖全桌面任意窗口

缺失：桌面 UI 控件抓取

没有接入 Windows UI Automation / macOS Accessibility API。无法枚举桌面上有哪些窗口、按钮、文本框。

目标：Windows UIA / macOS AX → 结构化 UI 树 → 可编程操控

缺失：系统级鼠标键盘模拟

没有 RobotJS / nut.js / pyautogui 层。鼠标键盘只能作用于浏览器内，无法操控桌面其他应用。

目标：系统级 mouse/keyboard API → 全桌面 click/type/drag/scroll

缺失：状态快照可回溯

没有 checkpoint/restore 机制。Agent 执行出错后无法回滚到之前的状态。

目标：操作前自动截图+状态采集 → checkpoint → 支持 restore/diff/undo

缺失：多模型路由

当前只对接了单一 LLM.server 端点。没有多模型注册/路由/降级/能力评估。

目标：ModelRegistry → 能力画像 → 智能路由 → 失败自动切换

缺失：全自主桌面闭环

Agent 在浏览器内能执行闭环，但出不了浏览器。桌面级"看→想→动→验"的完整循环尚未建立。

目标：DesktopAgentLoop = 看屏幕 → 理解UI → 计划动作 → 执行 → 验证结果 → 学习

已有但需深化：插件市场

PluginMarket 基础框架已存在，但缺少桌面级插件类型、UI控件插件、自动化脚本插件等扩展类别。

目标：支持桌面操控插件、视觉识别插件、自定义工作流插件的发布与热加载

已有但需深化：多设备协同

MultiDeviceCollaboration 已实现局域网设备发现和消息中继，但缺少桌面状态跨设备同步、远程操控能力。

目标：手机/平板可远程查看桌面状态、接收任务通知、跨设备任务接力

DesktopAgentLoop 核心循环伪代码 
async function desktopAgentLoop(task: string) {
  const intent = await intentRecognizer.recognize(task);
  const plan = await taskDecomposer.decompose(task);
  const checkpoint = await checkpointManager.create(`task-${Date.now()}`);

  for (const step of plan.subTasks) {
    const screenshot = await screenCapture.captureFullScreen();
    const vision = await desktopVision.analyzeScreen(screenshot);
    const uiTree = await desktopUIInspector.getUITree();
    const model = await modelRouter.selectBest(step);
    const action = await llm.decide(vision, uiTree, step);

    await mouse.moveTo(action.x, action.y);
    await mouse.click();
    await keyboard.type(action.text);

    await sleep(500);
    const after = await screenCapture.captureFullScreen();
    const diff = await diffEngine.diff(screenshot, after);
    const success = action.expectedState === diff.summary;

    if (!success) {
      await selfHealing.diagnose(action, diff);
      await undoManager.undo();
    }
    await reflection.recordExecution({ step, success, diff });
  }
}
