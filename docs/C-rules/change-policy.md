# Change Policy — 变更策略

> 定义 GLM 修问题时只能改对应层，不制造版本分叉。
> 修改此文件需人工审批。

## 变更类型与允许操作

### Bug 修复
| 操作 | 允许 | 说明 |
|------|------|------|
| 改 src/ 代码 | ✅ | 修复 bug 本身 |
| 追加 B 层审计 | ✅ | 记录修复结果 |
| 改 A 层 | ❌ | bug 修复不改变系统结构 |
| 改 C 层 | ❌ | 规则不变 |
| 改 D 层 | ✅ | 可记录修复过程 |

### 功能新增
| 操作 | 允许 | 说明 |
|------|------|------|
| 改 src/ 代码 | ✅ | 新增功能本身 |
| 更新 A 层 | ✅ | 新 Authority/任务需登记 |
| 追加 B 层审计 | ✅ | 记录验证结果 |
| 改 C 层 | ❌ | 除非新功能需要新规则 |
| 改 D 层 | ✅ | 可记录决策过程 |

### 重构
| 操作 | 允许 | 说明 |
|------|------|------|
| 改 src/ 代码 | ✅ | 重构本身 |
| 更新 A 层 | ✅ | 结构变化需更新 |
| 追加 B 层审计 | ✅ | 验证重构不破坏功能 |
| 改 C 层 | ❌ | 规则不变 |
| 改 D 层 | ✅ | 记录重构原因 |

### 文档操作
| 操作 | 允许 | 说明 |
|------|------|------|
| 合并多个文档 | ❌ | 制造版本分叉 |
| 重命名/移动文档 | ❌ | 破坏引用 |
| 修改历史审计 | ❌ | 违反审计规则 |
| 删除 archive/ | ❌ | 历史记录不可删 |
| 新增 4 层文档 | ✅ | 按治理架构写入 |

## 禁止操作清单

1. ❌ 不把多个文档合成一个
2. ❌ 不重命名/移动已有文档
3. ❌ 不修改 B 层历史审计数据
4. ❌ 不删除 archive/ 下的任何文件
5. ❌ 不自行修改 C 层规则文件
6. ❌ 不在根目录创建新的散落文档
