## 二、Phase A：架构对齐与核心增强（M1-M3）

### 2.1 模型架构优化

#### 2.1.1 注意力机制改进

**现状**: 贾百姓神经网络核心 (`neuralCore.ts`) 采用纯 TS 前馈网络，16 维输入→4 维输出，无注意力机制。

**目标**: 引入轻量级自注意力层，提升决策上下文关联能力。

**技术方案**:

```
输入层 (16维 DecisionFeatures)
    ↓
自注意力层 (Self-Attention, 4头)
    Q = X · W_q  (16×8)
    K = X · W_k  (16×8)
    V = X · W_v  (16×8)
    Attention(Q,K,V) = softmax(QK^T / √d_k) · V
    ↓
前馈层 (32→16 隐藏层)
    ↓
输出层 (4维: allow/ask/deny/confidence)
```

**参数量级规划**:

| 层级 | 参数量 | 显存占用 | 说明 |
|------|--------|---------|------|
| 自注意力 (4头×8维) | ~1,024 | <0.01 MB | 轻量级，GTX 1050 Ti 完全可承载 |
| 前馈隐藏层 | ~1,056 | <0.01 MB | 16→32→16 |
| 输出层 | ~68 | <0.01 MB | 16→4 |
| **总计** | **~2,148** | **<0.05 MB** | 纯 CPU 可训练 |

**实施步骤**:

1. **M1-W1-W2**: 在 `neuralCore.ts` 中实现 `SelfAttentionLayer` 类
2. **M1-W3-W4**: 重构 `NeuralNetwork` 类，支持可插拔层配置
3. **M2-W1-W2**: 集成到 `DecisionEnhancer`，对比无注意力基线
4. **M2-W3-W4**: 性能基准测试，确保推理延迟 <5ms

**验收标准**:
- 自注意力层单元测试通过
- 决策准确率较基线提升 ≥10%
- 推理延迟 ≤5ms (CPU)

#### 2.1.2 参数量级规划

**原则**: 贾百姓的神经网络不是 LLM，而是**决策增强器**，参数量级控制在万级以内。

| 模块 | 当前参数 | 目标参数 | 理由 |
|------|---------|---------|------|
| DecisionEnhancer | ~2,000 | ~5,000 | 增加注意力层 + 扩展隐藏层 |
| PatternRecognizer | ~1,000 | ~3,000 | 增加模式容量 |
| MoodClassifier | 0 (规则) | ~2,000 | 从规则迁移到轻量神经网络 |
| **总计** | **~3,000** | **~10,000** | 全部可在 CPU 上实时推理 |

### 2.2 训练数据构建

#### 2.2.1 数据采集范围

参照训练资源文档，优先选择低算力适配数据集：

| 数据类别 | 推荐数据集 | 规模 | 用途 |
|---------|-----------|------|------|
| 决策训练 | 自生成 (DecisionEngine 日志) | 10,000+ 条 | 决策增强器训练 |
| 情绪识别 | IMDB (情感二分类) | 5万条 | MoodClassifier 微调 |
| 指令理解 | alpaca-gpt4-zh | 5.2万条 | 指令解析优化 |
| 安全规则 | 自生成 (审计日志) | 5,000+ 条 | 安全边界训练 |
| 中文理解 | 中文 SmolTalk | 70万条 | 中文指令遵循 |

#### 2.2.2 数据清洗标准

```
输入数据 → 去重过滤 → 质量评分 → 格式标准化 → 训练集/验证集/测试集
    │          │          │           │              │
    │          │          │           │              └─ 7:2:1 拆分
    │          │          │           └─ 统一编码/格式
    │          └─ Jaccard 相似度 >0.85 去重
    └─ 原始采集
```

**清洗规则**:
- 去除空内容、纯标点、超长内容 (>4096 字符)
- Jaccard 相似度 >0.85 的条目去重
- 中文数据需确保 UTF-8 编码正确
- 安全相关数据需人工审核标注

#### 2.2.3 质量评估指标

| 指标 | 计算方式 | 合格阈值 |
|------|---------|---------|
| 数据完整率 | 非空字段数 / 总字段数 | ≥95% |
| 标注一致性 | 双人标注一致率 (Cohen's Kappa) | ≥0.8 |
| 去重率 | 重复条目数 / 总条目数 | ≤5% |
| 分布均衡度 | 最少类别样本数 / 最多类别样本数 | ≥0.3 |
| 噪声率 | 低质量样本数 / 总样本数 | ≤3% |

### 3.2 推理机制提升

#### 3.2.1 逻辑推理增强

**现状**: DecisionEngine 基于规则匹配 + 风险评估，无逻辑推理链。

**目标**: 引入 Chain-of-Thought (CoT) 推理能力。

**技术方案**:

```
用户指令
    ↓
[Think] 上下文分析 + 意图识别
    ↓
[Reason] 生成推理链 (前提→推导→结论)
    ↓
[Plan] 分解为子任务序列
    ↓
[Act] 逐步执行 + 中间验证
    ↓
[Reflect] 结果评估 + 经验记录
```

**实施步骤**:

1. **M4-W1-W3**: 在 `decisionEngine.ts` 中实现 `ReasoningChain` 类
2. **M4-W4**: 集成到 Lobster 循环的 Think 阶段
3. **M5-W1-W2**: 实现推理链的持久化和检索
4. **M5-W3-W4**: 推理准确率基准测试

#### 3.2.2 常识推理

**方案**: 构建轻量级常识知识图谱，存储在 `knowledgeGraph.ts` 中。

| 知识类型 | 示例 | 存储方式 |
|---------|------|---------|
| 物理常识 | "水在100°C沸腾" | 实体-属性-值 |
| 社交常识 | "深夜不宜打扰" | 情境-行为-评估 |
| 技术常识 | "rm -rf / 极危险" | 命令-风险-等级 |
| 时序常识 | "工作日上午9点忙碌" | 时间-状态-概率 |

**数据来源**: 
- 自建常识库 (优先，基于审计日志和用户反馈)

**核心原则**: 不从零预训练，基于开源预训练模型做微调。

| 训练任务 | 基座模型 | 训练方式 | 数据集 | 预计时间 |
|---------|---------|---------|--------|---------|
| 决策增强 | 自建前馈网络 | 在线增量训练 | DecisionEngine 日志 | 实时 |
| 情绪识别 | 微调 BERT-tiny | 4bit 量化微调 | IMDB + 自标注 | 2-4 小时 |

### 5.3 训练效率优化

| 优化技术 | 适用场景 | 预期加速 |
|---------|---------|---------|
| 4bit/8bit 量化 | LLM 微调 | 显存降低 4-8x |
| LoRA (r=8) | LLM 微调 | 参数减少 90%+ |
| 梯度累积 (steps=4) | 小 batch 训练 | 等效 batch=8-16 |
| 数据采样 | 大数据集 | 训练时间减少 50%+ |
| 早停 (patience=3) | 所有训练 | 防止过拟合 + 节省时间 |

### 7.3 最可能走通的技术路线

基于 OpenClaw 架构验证和 AGI 助手发展路径分析，**最可能走通的短期技术路线**为：

1. **架构层**: 网关-节点-渠道三层解耦 + Lobster 智能体循环 ✅ (OpenClaw 已验证)
2. **决策层**: 轻量神经网络 + 规则引擎混合 ✅ (贾百姓已实现，待增强)
3. **记忆层**: SQLite + 纯文本混合存储 ✅ (OpenClaw File-as-State 已验证)
4. **多模态层**: Ollama 本地推理 + 统一嵌入空间 ⚠️ (需验证 1050 Ti 性能)
5. **进化层**: 参数级自动优化 + 在线学习 ⚠️ (需验证稳定性)

**核心结论**: 贾百姓 AGI 助手在 6-12 个月内最可行的路径是**先完成架构对齐 (Phase A)**，这是所有后续能力的基础；**再推进多模态融合 (Phase B)**，这是 AGI 助手区别于普通聊天机器人的关键；**最后探索自主进化 (Phase C)**，这是通向 AGI 的长期方向但短期需谨慎。
