本地优先的 AI 具身 Agent · 演化蓝图 v2.0

🏗️ 当前架构总览

jiabaixing 采用单一御姐秘书人格 + 技能插件架构，核心大脑为 AgentLoop 配合 TaskDecomposer，调度 22 个已注册技能。记忆引擎 (MemoryEngine) 提供长期/短期记忆与用户画像，进化引擎 (RealTimeFeedbackLoop) 实现每次交互后的自我优化。

🧠 大脑与调度

  • IntelligentIntentRecognizer (18个二级意图)
  • AgentLoop 状态机 + TaskDecomposer
  • EnhancedSkillExecutor (重试/回退/超时)
  • AgentSelfReflection 自我反思

💾 记忆与人格

  • MemoryEngine (SQLite + Chroma 向量)
  • UserProfile 五维画像
  • PersonaCore + PersonaRules (场景语气)
  • LLMContextBuilder 智能记忆过滤

🖐️ 现有“手”与“眼”

  • PlaywrightSkill (浏览器操控+截图)
  • VisionEngine (图像分析/OCR)
  • FileSkill + CommandSkill
  • DockerSandbox 代码执行
  • IDESkill (VS Code/Cursor 集成)

  • 跨平台桌面自动化 (Win/Mac/Linux)
  • 像素级屏幕识别 + UI 控件树
  • 多模型后端 (Ollama, OpenAI, Anthropic)
  • 任务状态可回溯、可恢复
  • 丰富的 Skill 生态 (MCP 协议)

差距：桌面具身、模型路由、状态快照

Manus 特点

  • 云端沙箱执行环境
  • 浏览器 + 代码解释器 + 文件系统
  • ReAct 风格 Agent 循环
  • 长时间任务异步执行
  • 结果自动整理与交付

jiabaixing 优势：本地隐私、人格统一、记忆深度
差距：云端弹性、任务异步持久化

🎯 下一步开发重点 (2026 Q2-Q3)

🖥️ 桌面具身智能 (最高优先级)

让 jiabaixing 真正拥有“手”和“脚”，能操控任何桌面应用。

  • 引入 screenshot-desktop / mss 获取全屏/区域截图
  • 集成 nut.js 或 @nut-tree/nut-js 实现跨平台键鼠控制
  • Windows: 通过 node-win32-automation 或 PowerShell 调用 UIA
  • macOS: 调用 osascript / Accessibility API
  • 构建 DesktopSkill 统一接口，注册到 SkillRegistry
  • 实现“点击坐标(像素)”、“输入文本”、“拖拽”等原语

🔁 状态快照与回溯

借鉴数据库事务思想，让每一步操作可逆、可恢复。

  • 定义 Checkpoint 数据结构（屏幕截图+控件树+文件清单）
  • 每次关键操作前自动保存快照
  • 实现 rollback 机制（恢复到上一个快照）
  • 支持用户手动创建/命名检查点
  • 长期存储检查点序列用于审计

🧭 多模型路由与故障转移

不再依赖单一模型，根据任务难度和可用性智能选择。

  • 抽象 ModelRouter 层，管理多个后端
  • 支持本地模型 (Ollama/llama.cpp) + 云端 (OpenAI/Claude)
  • 基于意图复杂度自动路由：简单任务→本地，复杂推理→云端
  • 健康检查 + 自动故障转移
  • 成本追踪与使用统计

🤖 全自动办公 RPA 引擎

自然语言描述办公流程，jiabaixing 自动执行。

  • 结合屏幕识别 + UI 控件树定位元素
  • 录制与回放功能：用户示范一次，Agent 学会
  • 异常弹窗自动处理（基于 Vision 识别）
  • 跨应用工作流：Excel → 浏览器 → 邮件
  • 定时任务与条件触发
