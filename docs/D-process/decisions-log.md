## 2026-09-12: D9 跨任务泛化 + 文档治理

### 决策 1：H 系列任务独立文件
- **选择**：创建 HTasks.ts 而非修改 RealTasks.ts
- **原因**：RealTasks.ts 有 CRLF 编码问题，Edit 工具无法匹配
- **影响**：H 任务需从 HTasks.ts import，不影响功能

### 决策 2：4 层文档治理而非合并
- **选择**：A/B/C/D 四层分离，不合并旧文档
- **原因**：合并本身制造版本分叉，旧文档自然过期
- **影响**：新文档按 4 层模型写入，旧文档保留原位

### 决策 3：D9 测试分 4 Phase
- **选择**：训练→测试+Learning→测试-Learning→审计
- **原因**：需要对比有/无 Learning 的恢复率差异
- **影响**：测试运行时间较长（约 3 分钟）
