## 如何贡献

### 贡献流程

1. **创建文档**：在相应目录下创建新的文档
2. **编写内容**：按照文档模板编写内容
3. **提交审查**：提交Pull Request
4. **合并发布**：审查通过后合并到主分支

### 文档规范

1. **命名规范**：使用英文或中文拼音命名
2. **格式规范**：使用Markdown格式
3. **内容规范**：
   - 结构清晰，层次分明
   - 内容准确，示例完整
   - 及时更新，保持时效性

### 文档模板

```markdown
# 标题

## 概述
简要描述本文档的主要内容。

## 详细内容
详细描述相关知识。

## 示例代码
提供必要的代码示例。

## 注意事项
列出需要注意的事项。

## 参考资料
列出相关的参考资料。
```

## 知识库维护

### 维护责任

- **文档作者**：负责创建和更新自己编写的文档
- **模块负责人**：负责审核和更新所负责模块的文档
- **项目负责人**：负责整体知识库的质量把控

### 更新频率

- **重要文档**：每月至少更新一次
- **普通文档**：每季度至少更新一次
- **过时文档**：及时标记或删除
