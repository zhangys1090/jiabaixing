# jiabaixing 前端UI测试任务集

## 测试方案概述

- **测试入口**：前端UI界面（浏览器）
- **测试总量**：36个测试任务
- **覆盖模块**：聊天对话、技能系统、Agent执行、性能监控、进化面板、日志系统、设置面板、主题切换、语音交互
- **测试类型**：正常流程 / 异常场景 / 边界条件 / 性能测试
- **可重复性**：所有测试基于明确前置条件和固定数据，支持自动化回归

---

## 模块一：聊天对话系统（TC01-TC08）

---

### TC01: 发送文本消息并接收响应

**测试类型**：正常流程
**优先级**：P0

**前置条件**：

1. 后端服务已启动（`npm run start:backend`）
2. 前端已启动（`npm run start:frontend`）
3. WebSocket连接状态显示"已连接"
4. 当前位于"对话"模块

**操作步骤**：

1. 在消息输入框中输入文本："你好，请介绍一下自己"
2. 按下 Enter 键发送消息
3. 等待后端响应

**预期结果**：

1. 用户消息立即显示在聊天窗口中，状态为"已发送"
2. 输入框清空，显示占位符"jiabaixing 正在思考..."
3. 后端返回响应消息，显示在聊天窗口中
4. 响应消息支持Markdown渲染（如加粗、列表）
5. 输入框恢复为可输入状态

**验证方法**：

- [ ] 目视检查消息显示顺序（用户消息在上，助手消息在下）
- [ ] 检查消息时间戳是否正确
- [ ] 检查响应内容非空且语义合理
- [ ] 检查输入框状态变化（发送中 → 可输入）
- [ ] 浏览器控制台无报错

### TC03: 发送消息时网络断开（异常场景）

**测试类型**：异常场景
**优先级**：P0

**前置条件**：

1. 同 TC01
2. 浏览器开发者工具已打开（Network面板）

**操作步骤**：

1. 输入消息"测试网络断开"
2. 在发送前，使用浏览器开发者工具模拟网络断开（Offline模式）
3. 按下 Enter 发送消息
4. 观察界面反馈
5. 恢复网络连接
6. 等待自动重连

**预期结果**：

1. 网络断开时，WebSocket状态变为"未连接"（红色指示点）

4. 恢复网络后，自动重连成功（状态变回"已连接"）
5. 重连后用户可继续发送消息

**验证方法**：

- [ ] 检查WebSocket状态指示器颜色变化（绿→红→绿）
- [ ] 检查错误提示消息是否友好
