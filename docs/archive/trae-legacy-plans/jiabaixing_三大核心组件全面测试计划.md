# jiabaixing 三大核心组件全面测试计划

## 一、测试目标

基于 `docs/整合.md` 中描述的三大核心组件（大脑 CoreReasoningEngine、记忆 MemoryEngine、交互 InteractionEngine），设计并执行一套全面的测试方案，验证系统的前端UI表现与AGENT能力。

### 1.1 前端UI测试目标
- **功能完整性**：验证所有UI组件功能正确
- **交互流畅性**：确保用户操作响应及时、无卡顿
- **响应速度**：测量关键操作的延迟指标
- **视觉一致性**：确保UI风格统一、状态显示准确

### 1.2 AGENT能力测试目标
- **任务理解能力**：验证意图识别准确率
- **问题解决效率**：测量任务执行耗时与成功率
- **多轮对话连贯性**：验证上下文保持能力
- **结果准确性**：验证输出结果的正确性

### 3.4 多轮对话连贯性测试（MC-001~MC-003）

#### MC-001: 上下文保持
- **对话流程**:
  1. 用户："我叫张三"
  2. AI："你好张三，很高兴认识你"
  3. 用户："我叫什么名字？"
- **预期**: AI能正确回答"你叫张三"
- **检查点**:
  - MemoryEngine存储了用户信息
  - 第二轮能召回用户名字
  - 回复内容准确

#### MC-002: 话题切换
- **对话流程**:
  1. 用户："帮我写一个Python函数"
  2. AI：执行file skill，返回代码
  3. 用户："现在搜索一下配置文件"
  4. AI：执行search skill
- **预期**: 正确切换skill，无状态混淆
- **检查点**:
  - 每次对话intent识别正确
  - skill执行互不干扰
  - 响应内容对应正确skill

#### MC-003: 纠错学习
- **对话流程**:
  1. 用户："创建一个文件"
  2. AI：执行file skill（默认action=read）
  3. 用户："不对，我要写入内容"
  4. AI：纠正为action=write
- **预期**: 能根据用户反馈调整行为
- **检查点**:
  - FeedbackCollector记录纠错
  - 偏好记忆更新
  - 后续类似请求自动调整

| 级别 | 定义 | 处理时限 | 示例 |
