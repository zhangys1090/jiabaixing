### 3.1 PerformanceMonitor (GAP-02)

- 5种告警类型：连续失败、成功率下降、响应超时、错误突增、性能退化

```python
# 记录指标
```

- 性能退化检测：与基线比较，超过50%触发告警

**潜在改进**:

### 3.3 IncrementalPlanner (GAP-05)

**文件**: `agent/loop/incremental_planner.py` (467行)

#### 代码质量评分: ★★★★★ (5/5)

**优点**:

- 基于依赖图的影响范围分析（BFS广度优先搜索）
- 支持保留已完成步骤选项
- 步骤合并和重新排序
- 完整的变更记录和追踪
- 清晰的统计指标
- 完善的错误处理

**核心算法**:

```
1. 找到触发步骤
2. 构建依赖图（正向依赖）
3. BFS遍历所有受影响步骤
4. 保留未受影响步骤
5. 重新规划受影响部分
6. 合并并重新排序
7. 记录变更
```

**设计亮点**:

- `_analyze_impact()`: 基于依赖图的影响范围分析
- `_merge_plan()`: 智能合并，保持原有顺序
- `_record_changes()`: 完整的变更审计轨迹

**潜在改进**:

- 可以支持更复杂的重规划策略（如LLM辅助）
- 可以支持多步骤同时触发重规划
