### 🔧 项目级坑：husky pre-commit 在本仓库对 `*.ts` 必失败

- `.husky/pre-commit` = `npx lint-staged`；`.lintstagedrc.json` 仅匹配 `*.ts` 与 `*.{json,md,yaml}`，
  故**纯 Python 提交不触发**（提示 "could not find any staged files matching configured tasks"，正常放行）。
- 提交 `*.ts` 时 lint-staged 报 `× lint-staged failed due to a git error`，并留下
  `On main: lint-staged automatic backup` stash。**根因不是代码**：`core.autocrlf=true` +
  630+ 脏文件的超大工作树，使 lint-staged 的 stash/apply 流程失败。
- **正确处置**：先手动跑等价检查（`npx eslint --fix <files>` → `npx prettier --write <files>`
  → `npx tsc --noEmit`），确认全绿后 `git commit --no-verify`，并在 commit message 里
  写明"已手动执行等价检查 + 跳过原因"。切勿因钩子失败就放弃提交或改用 `git add .`。
- 事故后必查：`git status --short <files>`（改动是否还在暂存区）+ `git stash list`（backup 是否回收）。
