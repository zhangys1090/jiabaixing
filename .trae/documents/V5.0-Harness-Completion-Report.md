## 架构演进图

### V4.0（旧）→ V5.0（新）

```
V4.0 JiabaixingCore.processInput():
  ├─ 快速路径
  ├─ FC 循环路径（已删除）
  └─ 降级路径（DialogueGenerator）

V5.0 新流程：
  ┌─────────────────────────────────────────────────────────┐
  │ JiabaixingCore.processInput()                          │
  ├─ 调用 AgentHarness.processInput()                      │
  │   └─ 6层架构：                                           │
  │      ├─ Loop (Plan-Execute-Evaluate)                    │
  │      ├─ Context (宪法+记忆+动态+历史)                   │
  │      ├─ Tools (19个工具 + Schema验证 + 权限)             │
  │      ├─ Verification (安全检查+质量评分)                 │
  │      ├─ Constraints (预算+安全边界+钩子)                  │
  │      └─ Persistence (任务+对话+进化指标)                  │
  └─ 失败时降级到 DialogueGenerator                          │
```

## 降级容错链路

```
用户输入
    ↓
JiabaixingCore.processInput()
    ↓
  ┌─ 检查 Harness 是否可用？
  │   ├─ 是 → AgentHarness.processInput()
  │   │      └─ 6层架构处理
  │   │      └─ 成功 → 返回结果
  │   │      └─ 失败 → 降级到 DialogueGenerator
  │   └─ 否 → 直接降级到 DialogueGenerator
  │
  └─ DialogueGenerator 处理
      └─ 返回结果
```
