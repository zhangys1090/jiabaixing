5.1 P0 立即接入（6项）

P0-1：注册 Kanban/Cronjob/UIA 三个新工具

# 在 register_default_tools() 末尾添加：
from agent.tools.cronjob_tools import register_cronjob_tools
from agent.tools.windows_uia import register_uia_tools
register_cronjob_tools(registry)
count += 3
register_uia_tools(registry)
count += 3

P0-2：Evolution V2 引擎接入依赖图

# 在 dependencies.py 的 SUBSYSTEM_DEPS 中添加：
SubsystemSpec("evolution_v2", "_init_evolution_v2", ("evolution",), critical=False),

# 在 engine.py 中添加：
async def _init_evolution_v2(self) -> None:
    from agent.evolution.v2_engine import V2EvolutionEngine
    self.evolution_v2 = V2EvolutionEngine(self.evolution, self.memory)

P0-3：ToT 规划器集成到 Planner

# 在 loop/planner.py 的 plan() 方法中：
# 当 complexity == "complex" 时切换到 ToT 规划器
if complexity == "complex":
    from agent.loop.tot_planner import ToTPlanner
    tot = ToTPlanner(self.llm)
    plan = await tot.plan(input_text, budget, context)
else:
    plan = await self._plan_standard(input_text, budget, context)

P0-4：Debater 集成到 Controller

# 在 loop/controller.py 的 evaluating 阶段：
# 当存在多个候选方案时，触发辩论式决策
if len(candidates) > 1 and self._should_debate(context):
    from agent.loop.debater import Debater
    debater = Debater(self.llm)
    winner = await debater.debate(candidates, context)
    context.best_candidate = winner

核心发现

  1. 家百星整体接入率 ~80%：200+ 模块中约 160 个已通过 4 条路径接入主循环，架构组织良好。
  2. 最大缺口：新创建的工具（kanban_swarm, cronjob_tools, windows_uia）未注册到 register_default_tools()。
  3. ToT 和 Debater 是"沉睡的金矿"：已实现但未被主循环调用，是家百星相比 Hermes 的规划能力优势。
  4. Evolution V2 未接入依赖图：V2 代码自进化是家百星核心差异化，但未正式接入子系统。
  5. 评估系统大部分未启用：AB Comparator、Golden Eval、Assertion Validator 等已实现但未接入。
  6. LSP 完整栈底层未初始化：工具已注册但 LSP 客户端未启动，工具调用会失败。
