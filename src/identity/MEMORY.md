# MEMORY.md - 佳百姓 AI Agent 长期记忆规则

## 记忆存储规则

### 短期记忆

- 保留最近 200 条交互记录
- 每条记录包含: 时间戳、操作类型、结果摘要
- TTL: 2 小时后自动清理

### 长期记忆

- 存储项目结构变更、用户偏好、关键决策
- 使用向量索引支持语义检索
- 按场景标签分类: 编码、配置、调试、部署

## 用户偏好记录

- 编码风格: 简洁优先, 避免过度设计
- 沟通方式: 直接、结构化、少废话
- 审批策略: 非交互模式, 自动执行
